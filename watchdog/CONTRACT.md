# Watchdog implementation interface

Implementation contract for integration; operational instructions belong in README.md.

- Target runtime: static Linux Go binary, no target Go/Python; POSIX installer/launcher `hunter-watch.sh` at repo root. Build outputs `watchdog/bin/hunter-watch-linux-{amd64,arm64,386,arm}` via `watchdog/build.sh`.
- Native binary commands: `validate`, `check`, `watch`, `status`, `enable-recovery`, `disable-recovery`, `respond`.
- Common flags: `--config /PATH` default `/etc/hunter-watch/services.conf`, `--state-dir /PATH` default `/.x86` (engine uses its `watchdog/` child), `--log /PATH` default `/var/log/hunter-watch.jsonl`, `--interval N` default 30, `--owner local|wazuh` for enable-recovery. Native executable flags follow the command. `check` performs one tick; `watch` runs until SIGTERM. `validate` reads configuration without writes. `respond` reads one Wazuh 4.x JSON request from stdin.
- Config: UTF-8 plain pipe-delimited DATA, never shell; blank/comment lines permitted; twelve required fields: `id|kind|target|expect|unit|dependencies|policy|timeout|failures|cooldown|max_restarts|window`. `-` means no unit/dependencies/expected value. IDs/unit names restricted to safe names; dependencies comma-separated IDs. policy `alert` or `auto`. timeout 1–60 sec, failures 1–100, cooldown 1–86400 sec, max_restarts 1–100, window 1–86400 sec. Reject missing/unknown dependencies and cycles. Manifest must be regular, owned by current UID, not group/world writable.
- Kinds: `http` (URL, expect `200` or `200:literal-body`), `tcp` (host:port, expect `-`), `dns` (serverIP:port/query-name, expect address or `-`), `unit` (native service name, expect `-`), `disk` (absolute path, expect minimum free percent or `percent:inode-percent`), `mysql` (absolute private defaults-extra-file, expect `1`), `postgres` (serviceName@absolutePrivateServiceFile, expect `1`). Clients invoked directly with timeout, no shell/eval. unit recovery uses native systemd/OpenRC/SysV, requires root, explicit auto policy and persistent recovery switch; sensitive SSH/network/auth/database units refused by default.
- Recovery switch state `STATE/watchdog/recovery-owner`, absent means monitor-only. Single local owner: local ticks recover only owner=local; respond only owner=wazuh. `enable-recovery --owner ...` and disable are explicit phase-2 actions. Initial install MUST NOT create/enable this switch. Preserve existing switch on monitor reinstallation; offer explicit disable command.
- Events JSONL: module `hunter_watchdog`, host, service, event, timestamp, message, failures, recovery_result (where relevant). Events `OK`, `PENDING`, `UP`, `DOWN`, `RECOVERED`, `DEPENDENCY_DOWN`, `RECOVERY_ATTEMPT`, `RECOVERY_EXHAUSTED`, `RECOVERY_FAILED`, `RECOVERY_SUPPRESSED`, `CHECK_ERROR`. Only DOWN on threshold transition; health samples OK/PENDING level 0. Wazuh XML rules IDs 100700 base, 100701 UP, 100710 DOWN, 100711 RECOVERED, 100712 DEPENDENCY_DOWN, 100713 RECOVERY_ATTEMPT, 100714 RECOVERY_EXHAUSTED, 100715 RECOVERY_FAILED, 100716 RECOVERY_SUPPRESSED, 100717 CHECK_ERROR. No arbitrary event-to-shell execution. Stateless AR only accepts `add`, matching module, event DOWN, rule ID 100710 and allowlisted service, then freshly probes before any action.
- State lock covers checks/recovery; private JSON state retains failure counts and restart timestamps across invocations, cooldown + rolling attempt cap; malformed state fails closed. JSON log rotates bounded size; root flag/config unsafe symlinks rejected. Status reads state, not reset counters.
- Installer: `hunter-watch.sh install|check|status|enable-recovery|disable-recovery`, flags anywhere accepted so Coordinate can prepend `--state-dir`. `install --config LOCAL-MANIFEST` copies helper/config, creates root-owned monitor service/timer (systemd/OpenRC/cron fallback) with no recovery enabled, optional `--no-start` and fixture `--root DIR` for offline installation without live service actions. `HUNTER_WATCH_COLLECTOR` is temporary source binary from Coordinate, copied to `/usr/local/libexec/hunter-watch`; otherwise find built local binary. Existing logs/state preserved; validate before writes; no package installations/hardening. Root-only live install/actions. Config update staged/validated first; rollback on install activation error.
- Coordinate integration: add `watch` operation. Local wrapper flag `--watch-config FILE` embeds a chosen manifest via `write_watch_config` function; install needs it. Existing `--arch` selects watch helper too. Remote embeds binary with `write_watch_collector`; creates private manifest if provided; `HUNTER_WATCH_COLLECTOR` points to decoded temporary binary; installer receives its temporary config only for install. Accept `-- install|check|status|enable-recovery|disable-recovery [--owner local|wazuh]` after separator. Default watch action status; require config only for install. Collected watch output via normal stdout/stderr/status pipeline; log remains on host. Preserve setup/hunt/rootkit/harden semantics and tests.
